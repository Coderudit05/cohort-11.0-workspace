### Lesson Notes

#### Prerequisites
Before starting Tailwind CSS, it helps to know:
- Basic HTML
- Basic CSS
- How classes work in HTML
- A little JavaScript is helpful, but not required for the first session

#### Tailwind CSS Basic Connectivity Using CDN
The easiest way to begin with Tailwind CSS is by connecting it through a CDN.

This helps students:
- See Tailwind in action without installing anything
- Try utility classes immediately
- Understand how Tailwind changes the HTML styling workflow

This is a good first-class approach because the focus stays on learning the idea of utility classes before moving into setup and installation.

#### Tailwind CSS: What It Is
Tailwind CSS is a utility-first CSS framework.

That means instead of writing custom CSS for every design, you use small utility classes directly in your HTML to build the layout and style.

Example idea:
- `flex` for flexbox
- `p-4` for padding
- `text-center` for text alignment
- `bg-blue-500` for background color

#### Why Tailwind CSS?
Tailwind CSS is useful because it:
- Speeds up development
- Reduces the need to switch between HTML and CSS files
- Keeps styling consistent
- Makes responsive design easier
- Works well for rapid prototyping and real projects

#### What is a Library?
A library is a collection of pre-written code that you call when you need it.
- You control the flow
- You decide when to use the code
- It helps you avoid writing everything from scratch

#### What is a Framework?
A framework gives you a structure to build within.
- It often controls more of the flow
- You follow its rules and patterns
- It provides a stronger foundation for building applications

#### Bootstrap vs Tailwind CSS
Bootstrap and Tailwind both help you style websites, but they work differently.

Bootstrap:
- Comes with ready-made components
- Faster for traditional UI building
- More opinionated design style
- Easier for quick standard layouts

Tailwind CSS:
- Gives utility classes instead of pre-built components
- More flexible and customizable
- Encourages building your own design system
- Better when you want unique, custom UI

### Revision Summary
- Tailwind CSS is a utility-first framework.
- Libraries are called when needed; frameworks provide structure.
- Bootstrap is component-based; Tailwind is utility-based.
- Tailwind is great for speed, flexibility, and custom design.
